# Security Policy / Güvenlik Politikası

Please see below for our supported versions and reporting instructions.
Desteklenen sürümler ve bildirim talimatları için lütfen aşağıya bakın.

---

## 🇬🇧 English

### Supported Versions

| Version | Supported          | Notes |
| ------- | ------------------ | ----- |
| Latest  | :white_check_mark: | We highly recommend using the latest release. |
| < 1.0   | :x:                | Older versions are not maintained. |

### Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

If you believe you have found a security vulnerability in one of our projects, please report it to us as described below:

1.  **Email:** Send specific details to **[security@your-org-domain.com]**.
2.  **Encryption:** If possible, please encrypt your message using our PGP key (available at `[LINK TO KEY]`).
3.  **Response:** We will acknowledge your email within 48 hours.
4.  **Disclosure:** We ask that you give us a reasonable amount of time (90 days) to fix the issue before making it public.

### Güvenlik Açığı Bildirimi

**Lütfen güvenlik açıklarını herkese açık GitHub Issue'ları üzerinden bildirmeyin.**

Projelerimizden birinde bir güvenlik açığı bulduğunuzu düşünüyorsanız, lütfen aşağıdaki adımları izleyin:

1.  **E-posta:** Detayları **[security@your-org-domain.com]** adresine gönderin.
2.  **Şifreleme:** Mümkünse mesajınızı PGP anahtarımızı kullanarak şifreleyin.
3.  **Yanıt:** E-postanızı 48 saat içinde yanıtlayacağız.
4.  **İfşa:** Sorunu herkese duyurmadan önce, düzeltmemiz için bize makul bir süre (90 gün) tanımanızı rica ederiz.
